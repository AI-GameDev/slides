# Streamlit 소개

Python으로 데이터 앱을 빠르게 만들 수 있는 오픈소스 프레임워크

<v-clicks>

- <light-icon icon="brand-python" size="20px" /> **순수 Python** — HTML, CSS, JavaScript 없이 Python 코드만으로 웹 앱 개발
- <light-icon icon="click" size="20px" /> **간편한 UI** — 슬라이더, 버튼, 차트 등 위젯을 한 줄로 추가
- <light-icon icon="cloud-upload" size="20px" /> **즉시 배포** — Streamlit Community Cloud(무료) 또는 Snowflake를 통해 바로 배포
- <light-icon icon="puzzle" size="20px" /> **폭넓은 호환성** — Pandas, PyTorch, Matplotlib, Plotly 등 주요 라이브러리와 호환

</v-clicks>
