# Replit Streamlit Template

## Streamlit이란?

[Streamlit](https://streamlit.io/)은 Python으로 데이터 앱을 빠르게 만들 수 있는 오픈소스 프레임워크다.

- **순수 Python**: HTML, CSS, JavaScript 없이 Python 코드만으로 웹 앱 개발 가능
- **간편한 UI**: 슬라이더, 버튼, 차트 등 위젯을 한 줄로 추가
- **즉시 배포**: Streamlit Community Cloud(무료) 또는 Snowflake를 통해 바로 배포
- **폭넓은 호환성**: Pandas, PyTorch, Matplotlib, Plotly 등 주요 Python 라이브러리와 호환

## Streamlit 프로젝트 생성

### 1. 템플릿 선택

![Developer Frameworks 메뉴 진입](./images/replit-streamlit/step-01-framework-menu.png)

Replit 홈 화면의 왼쪽 사이드바에서 **Developer Frameworks** 메뉴를 클릭한다.

![Streamlit 템플릿 검색](./images/replit-streamlit/step-02-search-streamlit.png)

1. 검색창에 `streamlit` 입력
2. 검색된 Streamlit 템플릿 선택

### 2. 프로젝트 생성

![Remix 버튼](./images/replit-streamlit/step-03-remix.png)

**Remix** 버튼을 클릭하여 템플릿을 내 계정으로 복사한다.

![프로젝트 설정](./images/replit-streamlit/step-04-project-name.png)

1. **Name** 항목에 프로젝트명 입력
2. **Use Framework** 버튼 선택

### 3. 미리보기 확인

![새 탭 추가](./images/replit-streamlit/step-05-new-tab.png)

우측 패널의 **+** (New tab) 아이콘을 클릭한다.

![Preview 선택](./images/replit-streamlit/step-06-preview.png)

도구 목록에서 **Preview**를 선택하면 Streamlit 앱의 실시간 미리보기 화면이 활성화된다.

## Files 탭 활성화

![Files 아이콘](./images/replit-streamlit/step-07-files-icon.png)

우측 상단의 **Files** 아이콘을 선택한다.

![Files 탭](./images/replit-streamlit/step-08-files-tab.png)

Files 탭에서 프로젝트의 파일 구조(`main.py` 등)를 확인할 수 있다. 이제 `main.py` 파일을 수정하며 본격적으로 Streamlit 앱을 개발할 준비가 완료되었다.
